# My Collection TCG

Le carnet de bord d'une bande d'amis fans de TCG (Pokémon surtout, un peu One Piece et autres).

- **Mes Investissements** : acheter et revendre sans perte pour financer la collection.
- **Mes Classeurs** : suivi des sets dans les classeurs.
- **Mes Items** : produits scellés et ouverts, prix d'achat et valeur marché.
- **Wishlist** : cartes et items qu'on veut.
- **Ouvertures** : ce qu'on a ouvert entre amis, pour combien, ce qu'on a eu, avec un **classement de la chance** et son podium.

Site statique (HTML + Firebase Auth / Firestore), publié avec GitHub Pages : https://dcspacee.github.io/Ma-collection/
