📦 Mes Items

Inventaire complet de tous tes produits physiques — displays, ETB, UPC, tins, decks, blisters et plus. Compatible Pokémon, One Piece, Lorcana, Magic.

🔍
Scan code-barres
Tape ou scanne un code EAN. Recherche automatique sur Open Food Facts, fallback vers Cardmarket si introuvable.
🔔
Alertes de prix
Définis un seuil de prix par item. Badge visuel + notification navigateur (Web Push) quand le marché atteint ton objectif.
📈
Historique des prix
Enregistre des snapshots du prix marché avec la date. Un seul par jour, suppression possible depuis le détail.
⧉
Duplication rapide
Duplique un item en un clic depuis la grille ou le modal. Pratique pour les multiples exemplaires du même produit.
☁️
Sync intelligente
Fusion Firestore + localStorage par date de modification. Plus jamais de perte de données entre appareils.
💼
Lien vers Mes Investissements
Active le toggle sur un item pour l'inclure dans le suivi financier. Clic sur la ligne bleue → retour direct dans Mes Items.
🆕 Nouvelle page

🎯 Wishlist

Suis les cartes et produits que tu veux acquérir, avec priorités, budget et suivi du prix actuel observé.

🔴
Système de priorité
Haute / Moyenne / Basse — filtrable en sidebar. Bordure colorée sur chaque carte pour repérer les urgences d'un coup d'œil.
💰
Budget max vs prix actuel
Le prix actuel observé passe en vert si inférieur ou égal à ton budget — signal visuel immédiat pour savoir quand acheter.
✅
Bouton Acquérir
Marque un item comme acquis. Propose automatiquement de le transférer dans Mes Items avec les données pré-remplies (nom, jeu, prix d'achat).
🔗
Lien Cardmarket intégré
Stocke le lien Cardmarket de chaque item pour l'ouvrir directement sans chercher.

⚙️ Technique

Ce qui tourne sous le capot

100% statique, hébergé sur GitHub Pages, sans serveur ni abonnement.

🔥
Firebase Auth + Firestore
Connexion email/Google. Toutes les données stockées par utilisateur dans Firestore. Sync automatique multi-appareils avec fusion intelligente (localStorage + cloud par date de modification).
🃏
TCGdex API (Pokémon JP)
Gratuite, sans clé API. Toutes les extensions japonaises avec images, nombre de cartes et statuts de complétion.
🏴‍☠️
optcgapi.com (One Piece)
Gratuite, sans clé API. Extensions OP-01 à OP-15 + starter decks avec images hébergées sans restrictions CORS.
🔔
Web Push Notifications
Notifications navigateur natives pour les alertes de prix. Fonctionne sur GitHub Pages sans serveur. Une notification par item par session.
